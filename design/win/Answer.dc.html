What the menu says back
Curfew is not installed as a service on this PC yet, so nothing is being blocked.
To install it, open Windows Terminal or PowerShell as an administrator and run:
curfew install
Windows asks for administrator once, because a service any user could stop would not be much of a lock. The tray cannot do it for you, for the same reason.
To try Curfew without installing anything, run curfew run in an ordinary terminal and leave it open: it enforces for as long as it is running.
