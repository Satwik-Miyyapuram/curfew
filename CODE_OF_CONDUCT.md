# Code of conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be decent to each other. Harassment, personal attacks, and demeaning comments are not
welcome here -- in issues, in pull requests, or anywhere else the project is discussed.

Report problems privately to the repository owner through GitHub. Reports are handled
confidentially. Maintainers may warn, hide comments, or ban, in that rough order and depending on
severity.

One project-specific note: people use a blocker because they are struggling with something. Treat
reports about lockouts, relapses, or lost work with the seriousness they deserve, never as a
punchline.
